# Bounded integration change map

The supplied architectural handoff is retained verbatim under `context/`, with actual file hashes in `context_manifest.json`. It supplies design context; the user's message authorizes this bounded implementation. External platform adoption, a universal model, new acquisition and effectiveness claims are outside this pass.

| Responsibility | Before | This pass |
|---|---|---|
| Evidence custody | Existing bundle, original bytes, typed tree and ledger; source lookup embedded in app | `evidence.js`: revision/source/record/pointer resolver around the unchanged evidence. Custody is not factual truth. |
| Domain structure | `mapping.js` mixes identity membership, prefix/anchors and spatial Gaussian field | `domain.js`: queue adapter and source-linked exact partitions; origin, claim, lineage, world and alignment remain separate metadata dimensions. |
| Observation frame | Prefix selection and common history span inside app | `frames.js`: per-side windows before common display bounds, declared native/event-relative translations, carry-in separated from event observations. |
| Visual encoding | Four-category positions and Gaussian formula duplicated in mapping and renderer | `encoding.js`: one named required-work Gaussian preset. `mapping.js` remains a compatibility facade for existing checks. |
| Rendering | Mesh, material and camera existing; embedded domain assumptions; no shared fit | `renderer.js`: supplied encoding, common fit, clipping status and equal-style solo inspection. Geometry cache keyed by encoding/kernel/layout/weights/calibration. |
| Comparison | A/B state dispersed in app | `comparison.js`: paired source/world/event references, rationale, supported dimensions, separate windows, shared calibration, unaligned dimensions. |
| Saved analytic state | Export and restore assembled separately; restore omitted kernel/renderer checks | `session.js`: one compiled effective configuration drives renderer and exports; version/source validation and recomputation on restore. Meaningful manual checkpoints, not pointer histories. |
| Interface | Working spatial candidate | `app.js` and `shell.html`: retained body first, compact fit/frame controls, progressive source and contract inspection. |

Native and event-relative frame examples use identical retained records and counts. They change only declared time coordinates. Lifecycle stays optional; the renderer does not infer a cycle, frequency, new state, or physical geometry. Source bytes, the accepted prior viewer and all inherited accepted artifacts are protected by hashes. No core or `L_P` calculation is run.


## Linked instruments addition

- `labels.js`: versioned, checked initial-condition aliases and source references; frozen packets keep native IDs.
- `channels.js`: exact source record counts and event-only completions, with explicit unavailable values.
- `instruments.js`: Over time and same-event Relationship SVGs, using the shared observation frames and source channels.
- `frames.js`: optional nonpositive window pan; zero retains exact legacy behavior.
- `session.js`: optional instrument recipe, channel/range/cursor settings and pinned calibration/label versions; validates legacy saves before the modern UI defaults are applied.
- `timescale.js`: independent sampled calibration source and complex-Morlet transform stage.
- `timescale-ui.js`: raw signal, magnitude map, coefficient support, and explicit retrospective/prefix modes.
- `shell.html`, `app.js`, `build.py`: existing shell extended with linked views and offline assembly.

Evidence custody, queue interpretation, Gaussian encoding, body renderer, retained traces, and benchmark sources remain in their existing roles. The implementation does not call any data/benchmark producer.
